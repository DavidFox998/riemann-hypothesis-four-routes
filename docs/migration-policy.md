# Migration and Preservation Policy

1. Preserve the exact source revision before adapting any declaration.
2. Never infer mathematical status from Mathlib availability.
3. Record repository, revision, path, declaration, and reference.
4. Preserve a source theorem's proposition; document necessary API adaptation.
5. Keep historical, generated, and active publication trees distinguishable.
6. Do not replace a located result with `True`, an unnamed axiom, or a proxy.
7. Compile every publication-critical declaration through an active root.
8. Require parity review before privatizing a standalone route repository.
